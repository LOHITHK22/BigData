Developed a Python-based data processing pipeline that integrated API data fetching, Redis caching, and data visualization. 
Using a custom ApiReader class, I fetched task data from a public API and stored it in Redis for fast access with the RedisHandler class. 
I implemented data analysis and aggregation using the DataProcessor and Aggregation classes, allowing for the calculation of completed and incomplete tasks. 
Additionally, I created visual reports, including bar charts, pie charts, and histograms, using Matplotlib to display task completion status and user distribution. 
The project also featured a search functionality to filter tasks based on titles. This pipeline optimized task data processing by combining API integration, in-memory storage, and real-time data visualization.
